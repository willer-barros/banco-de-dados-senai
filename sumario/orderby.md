## ORDER BY

O ORDER BY serve para ordenar o resultado da consulta SQL por uma ou mais colunas, organizando os dados em ordem alfabética, numérica ou cronológica. Ele deve ser posicionado no final do comando SELECT.

Direções de Ordenação

ASC (Ascendente/Crescente): Ordena de A a Z, do menor para o maior número, ou da data mais antiga para a mais recente. É o comportamento padrão do SQL quando você não especifica o sentido.

DESC (Descendente/Decrescente): Ordena de Z a A, do maior para o menor número, ou da data mais recente para a mais antiga.
