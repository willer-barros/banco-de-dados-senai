## 🚀 Como Entregar Seus Exercícios (Fluxo de Fork & Pull Request)

Para realizar e entregar as suas atividades, utilizaremos o fluxo de **Fork**. Isso significa que você criará uma cópia deste repositório no seu perfil e, após concluir os exercícios, enviará uma solicitação de entrega para o professor.

Siga o passo a passo detalhado:

### 1. Fazer o Fork do Repositório
No canto superior direito desta página no GitHub, clique no botão **Fork**. Isso criará uma cópia exata deste projeto dentro da sua conta pessoal do GitHub.

### 2. Clonar o SEU Repositório Forkado
Abra o terminal na sua máquina, vá até a pasta de sua preferência e clone **o repositório que está no seu perfil** (certifique-se de que o seu nome de usuário aparece na URL):
```bash
git clone [https://github.com/SEU_USUARIO_DO_GITHUB/NOME_DO_REPOSITORIO.git](https://github.com/SEU_USUARIO_DO_GITHUB/NOME_DO_REPOSITORIO.git)
